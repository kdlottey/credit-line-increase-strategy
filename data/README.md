# Data

Put `UCI_Credit_Card.csv` in this folder.

- Download: [Kaggle: Default of Credit Card Clients Dataset](https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset)
- Original source: Yeh, I. C. (2009). *Default of Credit Card Clients* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55S3H
- License: CC BY 4.0

If the file is missing, the app downloads the same data from the UCI repository automatically.
